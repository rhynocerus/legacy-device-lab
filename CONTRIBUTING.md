# Contributing

Contributions that improve reproducibility, correct technical details or add evidence from the same hardware are welcome.

## Good contributions

- Confirming behavior on the same device model.
- Adding sanitized logs from a different Linux kernel, host controller or cable/port configuration.
- Documenting a reproducible workaround.
- Correcting device-specific details.
- Linking relevant upstream issues, patches or documentation.
- Improving the diagnostic methodology or helper scripts.

## Before opening an issue or pull request

Please include:

- exact device model and variant
- host operating system and kernel
- relevant tool versions
- steps to reproduce
- expected result
- actual result
- sanitized logs when useful

## Privacy and log hygiene

Do not publish passwords, tokens, private keys, unnecessary serial numbers, MAC addresses, personal email addresses or other identifiers that are not needed to reproduce the issue.

## Pull requests

Keep pull requests focused on one case or one improvement. Explain what changed and why, and mention any physical-device testing performed.

## Third-party projects

Do not copy third-party code into this repository without preserving its license and attribution. Prefer linking upstream and contributing fixes to the original project whenever possible.
